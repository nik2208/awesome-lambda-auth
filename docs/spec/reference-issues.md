# Reference-family issues found during Phase 0 recon

Rule of engagement §8: *source beats documentation; doc bugs get reported.* This file collects every doc-vs-code disagreement, bug, and cross-client inconsistency found while extracting the wire contract. Commits pinned per [recon-manifest.md](recon-manifest.md). Items marked **[filed]** already have a GitHub issue.

**Revision note (2026-07-29):** merged with the adversarially-verified contract extraction ([wire-contract.md](wire-contract.md) + `_extract/01`–`09`). Every entry is grounded in a verified `file:line`; `[UNTESTED]` markers from the extraction carry through where relevant. **Disposition legend:** *fix-upstream* (issue/PR against the reference), *document* (report + `CompatibilityNotes()` entry in the port), *reproduce* (port keeps the behavior verbatim for wire compat), *decide* (candidate port deviation — needs explicit sign-off per rules of engagement).
