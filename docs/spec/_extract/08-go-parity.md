# 08 — Go parity

## Go parity matrix (node vs go, code-verified)

Scope: per-capability parity between `awesome-node-auth` v1.9.0 (reference, pinned cc01e997; version confirmed in `package.json`) and `awesome-go-auth` @4b2fc5c. Every claim below is grounded in source or test code of the two repos (paths relative to each repo root). The Go port is architecturally different from the reference: it is a **service-layer library** (`Service` methods on a struct) with thin optional HTTP adapters, whereas the Node reference is **router-first** (four Express routers exposing the full wire contract). Consequently most capabilities exist in Go as callable Go functions but have **no HTTP surface**, and the five routes that do exist diverge from the family wire contract in cookie names, JSON casing, response envelopes and error bodies. This section feeds `parity-gap-node-vs-go.md`, not `wire-contract.md`.

Status legend — **WC** Implemented-and-wire-compatible · **DIV** Implemented-but-diverges · **SVC** Service-layer-only (no HTTP) · **ABS** Absent.

### Token builders side by side (the single deepest wire break)

Node (src/services/token.service.ts:20-29) — standard JWTs, split secrets:

```ts
const accessToken = jwt.sign(claims, config.accessTokenSecret,
  { expiresIn: config.accessTokenExpiresIn ?? '15m' });
const refreshToken = jwt.sign(claims, config.refreshTokenSecret,
  { expiresIn: config.refreshTokenExpiresIn ?? '7d' });
```

Go (token.go:59-65) — custom 2-part format, one secret:

```go
raw, err := json.Marshal(payloadClaims)
...
payload := base64.RawURLEncoding.EncodeToString(raw)
sig := sign(payload, s.cfg.Secret)          // HMAC-SHA256, security.go:69-73
return payload + "." + sig, expiresAt, nil  // <payload>.<sig> — no JOSE header
```

Everything downstream of a token — clients decoding claims, `auth.js`, gateway JWT authorizers, the Angular/Flutter interceptors — breaks on the Go format (issue #8). Note the irony pinned in idp.go:282-301: the Go repo already contains a correct stdlib 3-part JWT builder (`buildRS256JWT`), used only for ID tokens.
